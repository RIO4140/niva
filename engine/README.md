# نيفا — المحرك

محرك تنفيذ: Lexer + Parser + AST +
مترجم إلى بايت كود وآلة افتراضية، مكتوب بـ Rust،
ولا يحوّل برامج نيفا إلى لغة آلة بعد.

## البناء والتشغيل

البناء يحتاج أدوات Rust فقط (cargo/rustc). التشغيل لا يحتاج شيئا
آخر: الملف التنفيذي الناتج مستقل بذاته.

```bash
cargo build --release
./target/release/نيفا examples/01-hello.نيفا
./target/release/نيفا examples/08-full-program.نيفا
./target/release/نيفا program.نيفا --شجرة   # اطبع شجرة AST ثم شغّل
./target/release/نيفا                     # دخول الوضع التفاعلي
cargo test                                # اختبارات الوحدة والتكامل
```

## الوضع التفاعلي

`نيفا` بلا ملف (أو `نيفا --تفاعلي`) يفتح الوضع التفاعلي:
المتغيرات والدوال تبقى عبر السطور، والتعبير وحده
يطبع قيمته، والكتل تكمل بسطور إضافية (سطر فارغ
يلغي الكتلة). الأوامر: `:مساعدة` و`:اعرض` و`:مسح`
و`:خروج`. التشغيل الافتراضي هو المترجم، وتشكيل
الحروف العربية يعتمد على الترمنال نفسه — وعلى
الطرفيات الأخرى قد يظهر الكود من الشمال لليمين؛
التجربة الكاملة بالعرض الصحيح هي في تطبيق
ترمنال نيفا.

## أمثلة

انظر مجلد `examples/`: طباعة، متغيرات، شروط، حلقات
(بما فيها `كرر N مرات` و`كرر طالما`)، دوال، قوائم وقواميس،
محاولة وأخطاء وملفات، وبرنامج درجات كامل،
ووحدات وأنواع.

## قواعد

- متغير الدالة محلي فقط، ومتغير الحلقة متاح بعدها.
- الشروط يجب أن تكون منطقية.
- التحويل الصريح فقط عبر `عدد()` و`نص()`.
- رسائل الأخطاء بالعربي، بالسطر والعمود والنوع.
- الوحدات: `استورد وحدة`، و`صدّر` للأسماء العامة،
  والوصول بالنقطة `وحدة.اسم`.
- المكتبة القياسية: `رياضيات` (جذر، قوة، جيب،
  جيب_تمام، ظل، لوغاريتم، أس_طبيعي، أرضية، سقف،
  باي، هـ)، و`عشوائي` (عدد_عشوائي، صحيح_عشوائي،
  اختيار)، و`وقت` (الآن، نوم).
- الأنواع اختيارية: `س: عدد = ٥`،
  و`دالة جمع(أ: عدد): عدد:`.
- الفئات: `فئة اسم:`، وإنشاء بـ `أنشئ اسم(...)`،
  ومنشئ باسم `أنشئ`، و`نفس` داخل الطرق.
- الملفات مقيدة بمجلد البرنامج افتراضيا،
  والمسار النسبي نسبة لمجلد البرنامج،
  و`--اسمح-بالكل` للبرامج الموثوقة التي تحتاج
  ملفات خارج مجلد البرنامج.
- التشغيل الافتراضي هو المترجم (الآلة الافتراضية).

## الأنظمة المستهدفة

الكود std فقط ومحمول، ويُبنى لـ Windows وmacOS وLinux وAndroid.
والمحرك نفسه يعمل داخل تطبيق ترمنال الأندرويد (مبني بـ NDK).
