# نيفا — إضافة VS Code

دعم لغة نيفا العربية في VS Code: تمييز الصياغة لملفات
`.نيفا`، وتعليق `#`، وأقواس، وقواعد مسافة بادئة.

## التثبيت (محلي)

انسخ هذا المجلد إلى مجلد إضافات VS Code، ثم أعد تشغيل
المحرر:

```bash
cp -r editors/vscode ~/.vscode/extensions/نيفا
```

أو احزمها بـ `vsce package` وثبت ملف `.vsix`.

## ما يغطيه التمييز

- كل الكلمات المحجوزة (اطبع، إذا، دالة، فئة، استورد...).
- النصوص والتعليقات والأرقام (العربية والغربية).
- أسماء الدوال والفئات بعد `دالة` و`فئة` و`أنشئ`.
- الدوال المدمجة (طول، مدى، مجموع...) عند استدعائها.
- أنواع التدرج (عدد، نص، منطقي، قائمة، قاموس، أي...).
- وحدات المكتبة القياسية (رياضيات، عشوائي، وقت، شبكة).
- الوصول بالنقطة (طرق وحقول).

## النشر في السوق

النشر في سوق VS Code خطوة منفصلة تحتاج حساب ناشر
ورمز وصول — ليست في هذه النسخة.
