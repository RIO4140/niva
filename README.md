# نيفا — لغة برمجة بالعربي

[![CI](https://github.com/RIO4140/niva/actions/workflows/ci.yml/badge.svg)](https://github.com/RIO4140/niva/actions/workflows/ci.yml)

نيفا لغة برمجة عربية كاملة: تكتب الكود بالعربي، وتشغّله في ترمنال نيفا الرسمي، أو جرّبه في الملعب في المتصفح.

صنع بواسطة محمود عبد النبي.

## تنزيل ترمنال نيفا

التجربة الكاملة للغة — بالعرض الصحيح من اليمين لليسار — في تطبيق ترمنال نيفا الرسمي:

- أندرويد: [niva-terminal-1.2.19.apk](https://github.com/RIO4140/niva/releases/download/v1.2.19/niva-terminal-1.2.19.apk)
- ويندوز: قريبا
- ماك: قريبا

نيفا تعمل في ترمنال نيفا الرسمي فقط، لأن الطرفيات الأخرى تعرض الكود من الشمال لليمين بلا وصل.

## جرّب بلا تثبيت

[الملعب](https://rio4140.github.io/niva/playground/) — اكتب كودا بالعربي وشغّله في المتصفح فورا.

## المحرك

محرك تنفيذ مكتوب بـ Rust (الإصدار 1.0.0)، يعمل داخل ترمنال نيفا الرسمي. تشغّل برنامجك بأمر واحد داخل الترمنال: `نيفا برنامج.نيفا`.

وللتجميع الأصلي: `نيفا ابن --أصلي برنامج.نيفا` يبني ثنائيا أصليا يعمل وحده.

وأمر `ابن` وحده يبني ملف `.نيفاب` يعمل على أي جهاز فيه نيفا، و`ابن --مستقل` يبني ملفا تنفيذيا مستقلا.

المحرك يعمل داخل تطبيق ترمنال الأندرويد.

## الوضع التفاعلي

في ترمنال نيفا الرسمي، افتح الوضع التفاعلي (بلا ملف، أو بـ `نيفا --تفاعلي`):
اكتب جملة في سطر، والتعبير وحده يطبع قيمته،
والكتل (دالة، إذا، بينما...) تكمل بسطور إضافية،
وسطر فارغ يلغي الكتلة. الأوامر: `:مساعدة` و`:اعرض`
و`:امسح-المحفوظات` و`:مسح` و`:اسمح-بالشبكة` و`:خروج`.

انظر `engine/README.md` للأمثلة.

## المكتبة القياسية

المكتبة القياسية واسعة وتغطي النص والملفات والنظام والشبكة والحزم والطرفية والمراقبة. منها:

- `رياضيات`: جذر، قوة، جيب، جيب_تمام، ظل، لوغاريتم،
  أس_طبيعي، أرضية، سقف، والثابتان باي وهـ.
  الزوايا بالراديان.
- `عشوائي`: عدد_عشوائي (من 0 إلى 1)،
  صحيح_عشوائي (من حد أدنى إلى حد أقصى)،
  اختيار (عنصر عشوائي من قائمة).
  عشوائية للألعاب والمحاكاة، لا للتشفير.
- `وقت`: الآن (ثواني منذ 1970)، نوم (ثواني).
- `بحث`: بحث نصي بخيارات كثيرة — مطابقة، تجاهل حالة، تعبيرات، وملفات.
- `فرق`: مقارنة ملفات ونصوص وإظهار الفروق.
- `جسون`: قراءة وكتابة JSON.
- `ملفات`: قراءة وكتابة ونسخ ونقل ومزامنة الملفات والمجلدات.
- `شبكة`: اجلب (رابط) — جلب HTTP بنص، مغلقة افتراضيا،
  وتفتح بعلم `--اسمح-بالشبكة`؛ النسخة الأصلية تقبل HTTP
  فقط وترفض HTTPS، أما الملعب فيقبل HTTPS.
- `عمليات`: أنشئ (أمر) — تشغيل برنامج خارجي وانتظاره
  وإيقافه، والحالية (معرف العملية)؛ خاملة في الملعب،
  والتشغيل مرفوض في التطبيق.
- `حزم`: مدير الحزم — تثبيت الحزم من GitHub،
  وأمر `حدث حزم` يحدّثها.

```
استورد رياضيات
اطبع رياضيات.جذر(16)
```

## المميزات

- متغيرات، طباعة، شروط، حلقات، دوال، قوائم، قواميس،
  فهرسة، محاولة/ماعدا/أخيرا، تعليقات، نصوص، أرقام
  عربية وغربية، ترقيم عربي.
- مطابقة أنماط: `طابق` و`حال` مع أنماط كثيرة.
- صفوف ومجموعات وفهميات لبناء القوائم والقواميس.
- مولدات: `ولد` و`ولد من` — تعمل مع التشغيل العادي،
  والثنائي الأصلي يرفضها برسالة واضحة.
- مديرو سياق: `عند` لإدارة الموارد.
- أنواع عامة وأنواع اختيارية: مثل `س: عدد = ٥`،
  و`دالة جمع(أ: عدد): عدد:`، و`أي` يعني بلا فحص.
- فئات بسيطة: `فئة نقطة:`، وإنشاء بـ `أنشئ نقطة(٣، ٤)`،
  وطرق وحقول بالنقطة، و`نفس` داخل الطرق،
  ووراثة بـ `ورث`، وواجهات بـ `واجهة`.
- وحدات: استيراد ملفات `.نيفا`، وتصدير الأسماء العامة،
  والوصول إليها بالنقطة.
- أخطاء بالعربي، بالسطر والعمود ونوع الخطأ.
- الملفات مقيدة بمجلد البرنامج افتراضيا،
  و`--اسمح-بالكل` للبرامج الموثوقة فقط.
- ملعب متصفح (WebAssembly) في `playground/`:
  اكتب كودا بالعربي وشغّله بلا تثبيت. الملفات والإدخال
  والنوم غير مدعومة فيه.
- إضافة VS Code في `editors/vscode/`:
  تمييز صياغة لملفات `.نيفا`.
- خادم لغة (LSP) في `editors/lsp/`:
  تشخيصات وإكمال وتمرير فوق stdio (`niva-lsp`).

## قواعد اللغة (مختصرة)

- لغة صورية بكلمات محجوزة ثابتة بالفصحى، ليست جملا عربية حرة.
  الجملة العربية الحرة لن تعمل، وهذا تعريف أي لغة برمجة في العالم.
- الكود يُعرض من اليمين لليسار (مثل القراءة العربية)، والكلمات العربية
  رموز داخله. النصوص العربية داخل علامات التنصيص لا تترجم أبدا.
- المحلل متسامح: يشيل التشكيل، ويوحد الهمزات في الكلمات المحجوزة فقط،
  ويقبل الأرقام العربية المشرقية ٠١٢٣ والغربية 0123، والفاصلة العربية ،
  والفاصلة المنقوطة العربية ؛.
- أسماء المتغيرات: كلمة واحدة من غير مسافات، عربي أو إنجليزي.
  التنضيف فيها للتشكيل فقط، فـ مدرسة ليست مدرسه، ولا يدمجهما المحلل.
- `اطبع` تعمل بأقواس ومن غير أقواس: `اطبع "مرحبا"` و `اطبع("مرحبا")`.
- الدالة تفتح نطاقا جديدا، ومتغير داخلها غير متاح خارجها.
  الحلقة والشرط لا يفتحان نطاقا، ومتغير الحلقة يبقى بعدها.

## مثال كامل

كود نيفا:

```
دالة تقدير(درجة):
    إذا درجة >= ٩٠:
        ارجع "ممتاز"
    وإلا إذا درجة >= ٥٠:
        ارجع "ناجح"
    وإلا:
        ارجع "راسب"
اطبع تقدير(٨٥)
```

الناتج:

```
ناجح
```
