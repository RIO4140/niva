# Rio4140 — لغة برمجة بالعربي

أداة شخصية مستقلة، مبنية من الصفر، لصاحبها محمود عبد النبي.
ليست شبكة أدوات، وليست تابعة لأي مؤسسة، وليست تطبيق موبايل.

## المسار الثاني: المحرك المستقل (Rust، دون Python)

المحوّل إلى Python (أدناه) كان المسار الأول، وهو طريق التخرج.
المسار الثاني هو محرك تنفيذ مستقل تماما عن Python، مكتوب بـ Rust:
Lexer + Parser + AST + Tree-Walking Interpreter، بملفات ‎.rio،
وبدون Compiler إلى لغة آلة في v1، وبدون Python لتشغيل البرامج.

```bash
cd engine
cargo build --release
./target/release/rio examples/08-full-program.rio
cargo test   # 9 اختبارات وحدة + 6 اختبارات تكامل
```

انظر `engine/DESIGN.md` لقواعد AST وScope وType System
وError Handling بالعربي، و`engine/README.md` للتشغيل.
الكود std فقط ومحمول، فيمكن بناؤه لـ Windows وLinux وAndroid،
والنسخة المبنية هنا Linux، وبناء Windows وAndroid خطوة إصدار لاحقة.

## المسار الأول: المحوّل إلى Python (طريق التخرج)

أداة شخصية مستقلة، مبنية من الصفر، لصاحبها محمود عبد النبي.
ليست شبكة أدوات، وليست تابعة لأي مؤسسة، وليست تطبيق موبايل.
هي أداة للمبرمجين: تكتب كود بالعربي، فيتحول إلى كود Python حقيقي
يشتغل في أي مكان، من غير Rio4140.

## الفكرة في جملة واحدة

Rio4140 جسر، ليست قفصا. هدفها أن تتعلم البرمجة بالعربي،
ثم تتخرج إلى Python وتكتب Python من غيرها.
نجاحها يقاس بعدد الخريجين، لا بعدد النجوم والتحميلات.

## التشغيل

```bash
python3 rio4140.py examples/01-hello.rio --run
python3 rio4140.py program.rio            # يكتب program.py بجانبه
python3 rio4140.py program.rio --stdout   # يطبع كود Python فقط
python3 rio4140.py --keywords             # جدول الكلمات المحجوزة
python3 tests/run_tests.py                # اختبارات الأمثلة العشرة
```

الملعب: افتح `playground/index.html` في متصفحك.
لا يرسل كودك لأي سيرفر أبدا. التشغيل في متصفحك فقط،
أو بتصدير ملف Python وتشغيله على جهازك.

## قواعد اللغة

- لغة صورية بكلمات محجوزة ثابتة بالفصحى، ليست جملا عربية حرة.
  الجملة العربية الحرة لن تعمل، وهذا تعريف أي لغة برمجة في العالم.
- اتجاه الكود مثل لغات العالم (من الشمال لليمين)، والكلمات العربية
  رموز داخله. النصوص العربية داخل علامات التنصيص لا تترجم أبدا.
- المحلل متسامح: يشيل التشكيل، ويوحد الهمزات في الكلمات المحجوزة فقط،
  ويقبل الأرقام العربية المشرقية ٠١٢٣ والغربية 0123، والفاصلة العربية ،
  والفاصلة المنقوطة العربية ؛.
- أسماء المتغيرات: كلمة واحدة من غير مسافات، عربي أو إنجليزي.
  التنضيف فيها للتشكيل فقط، فـ مدرسة ليست مدرسه، ولا يدمجهما المحلل.
- أسماء الدوال الخاصة في Python (مثل `__init__`) تبقى إنجليزية،
  لأن Python نفسه يطلبها كذلك.
- `اطبع` تعمل بأقواس ومن غير أقواس: `اطبع "مرحبا"` و `اطبع("مرحبا")`.

## مثال كامل

كود Rio4140:

```
دالة تقدير(درجة):
    إذا درجة >= ٩٠:
        ارجع "ممتاز"
    وإلا إذا درجة >= ٥٠:
        ارجع "ناجح"
    وإلا:
        ارجع "راسب"
اطبع تقدير(٨٥)
```

كود Python الناتج (يعمل وحده، من غير Rio4140):

```python
def تقدير(درجة):
    if درجة >= 90:
        return "ممتاز"
    elif درجة >= 50:
        return "ناجح"
    else:
        return "راسب"
print(تقدير(85))
```

## الاختبارات الرسمية (من التيرمينال)

لا تحتاج أي مكتبات خارجية، Python القياسي يكفي:

```bash
python3 -m unittest discover -s tests -v   # اختبارات الوحدة: 19 اختبارا
python3 tests/run_tests.py                 # اختبارات التكامل: الأمثلة العشرة
```

اختبارات الوحدة في `tests/test_transpiler.py` تغطي: الكلمات المحجوزة كلها،
المحلل المتسامح (همزات، تشكيل، أرقام عربية، ترقيم عربي)، بقاء أسماء
المتغيرات متميزة، عدم ترجمة النصوص والتعليقات أبدا، تشغيل الكود الناتج
فعلا، واجهة سطر الأوامر، وملعب المتصفح. أي اختبار يفشل يعني المحول غلط،
مش الاختبار. والاختبارات نفسها طوّرت المحول: كشفت أن التشكيل داخل
الكلمة كان يكسرها، فاتصلح قبل النشر.
