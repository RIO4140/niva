# Rio — لغة برمجة بالعربي

> اسم اللغة الآن **Rio** (سابقا Rio4140، حتى 2026-11-05، بقرار صاحب اللغة).
> Rio4140 يبقى هوية صاحب اللغة (محمود عبد النبي)، لا اسم اللغة.

أداة شخصية مستقلة، مبنية من الصفر، لصاحبها محمود عبد النبي.
ليست شبكة أدوات، وليست تابعة لأي مؤسسة، وليست تطبيق موبايل.

## قاعدة ملزمة: لا اعتماد على Python نهائيا

Rio لا تعتمد على Python في التشغيل، ولا في المحرك،
ولا في الاختبارات. المحوّل إلى Python أزيل من Rio
خالصا في 2026-11-05، بأمر صاحب اللغة، وملفاته في
سلة المهملات القابلة للاستعادة حتى 2026-12-05،
ولا تعتبر جزءا من Rio بعد الآن. الوثائق التاريخية
(v1.0–v1.3) تحتفظ بالاسم والمسار القديمين كتاريخ فقط.

## المحرك المستقل (Rust، دون Python)

محرك تنفيذ مستقل تماما عن Python، مكتوب بـ Rust:
Lexer + Parser + AST + Semantic Analyzer +
Tree-Walking Interpreter، بملفات `.rio`، وبدون
Compiler إلى لغة آلة في v1، وبدون Python لتشغيل البرامج.

الكود std فقط ومحمول، فيمكن بناؤه لـ Windows وLinux
وAndroid، والنسخة المبنية هنا Linux، وبناء Windows
وAndroid خطوة إصدار لاحقة.

## التشغيل

البناء بيحتاج Rust بس، والتشغيل بعد البناء مش بيحتاج
لا Python ولا Rust:

```bash
cd engine
cargo build --release
./target/release/rio examples/01-hello.rio
./target/release/rio program.rio
cargo test   # اختبارات المحرك: 9 وحدة + 11 تكامل
```

الملف التنفيذي `rio` بيشتغل لوحده، و`ldd` عليه بيطلع
بس `libc` و`libgcc`، ومفيش `libpython` خالص.

انظر `engine/DESIGN.md` لقواعد AST وScope وType System
وError Handling بالعربي، و`engine/README.md` للتشغيل،
و`engine/STATUS-REPORT.md` لما تم بناؤه واختباره فعلا،
لا التصميم وحده.

## الحالة الحالية (منفذ ومختبر فعلا)

- متغيرات، طباعة، شروط، حلقات، دوال، قوائم، قواميس،
  فهرسة، محاولة/ماعدا/أخيرا، تعليقات، نصوص، أرقام
  عربية وغربية، ترقيم عربي.
- 27 كلمة في Lexer، منها 23 منفذة، و2 مرفوضة صراحة
  (فئة، استورد)، و2 محجوزة غير مستخدمة (من، باسم).
- 12 دالة مدمجة، بالإضافة إلى `اطبع` كجملة.
- محلل دلالي قبل التنفيذ: متغير غير معرف، وارجع
  خارج دالة، واكسر/تابع خارج حلقة، وعدد معاملات
  خاطئ، كلها أخطاء عربية قبل أي تنفيذ.
- حد عمق استدعاء 200، وحد تكرار 1,000,000،
  كلاهما بخطأ عربي، لا انهيار.

## ما لم ينفذ بعد (هدف مستقبلي، لا إنجاز)

- فئات، ووحدات/استيراد، ووصول بالنقطة، وBytecode VM،
  وGC، ومصحح، ومدير حزم، ومكتبة قياسية بوحدات.
  مواصفتها في وثيقة `ENGINEERING-DESIGN-v1.3.md`،
  وتنفيذها في Phase 1A وما بعدها، لا في هذه النسخة.

## قواعد اللغة (مختصرة)

- لغة صورية بكلمات محجوزة ثابتة بالفصحى، ليست جملا عربية حرة.
  الجملة العربية الحرة لن تعمل، وهذا تعريف أي لغة برمجة في العالم.
- اتجاه الكود مثل لغات العالم (من الشمال لليمين)، والكلمات العربية
  رموز داخله. النصوص العربية داخل علامات التنصيص لا تترجم أبدا.
- المحلل متسامح: يشيل التشكيل، ويوحد الهمزات في الكلمات المحجوزة فقط،
  ويقبل الأرقام العربية المشرقية ٠١٢٣ والغربية 0123، والفاصلة العربية ،
  والفاصلة المنقوطة العربية ؛.
- أسماء المتغيرات: كلمة واحدة من غير مسافات، عربي أو إنجليزي.
  التنضيف فيها للتشكيل فقط، فـ مدرسة ليست مدرسه، ولا يدمجهما المحلل.
- `اطبع` تعمل بأقواس ومن غير أقواس: `اطبع "مرحبا"` و `اطبع("مرحبا")`.
- الدالة تفتح نطاقا جديدا، ومتغير داخلها غير متاح خارجها.
  الحلقة والشرط لا يفتحان نطاقا، ومتغير الحلقة يبقى بعدها.

## مثال كامل

كود Rio:

```
دالة تقدير(درجة):
    إذا درجة >= ٩٠:
        ارجع "ممتاز"
    وإلا إذا درجة >= ٥٠:
        ارجع "ناجح"
    وإلا:
        ارجع "راسب"
اطبع تقدير(٨٥)
```

الناتج:

```
ناجح
```
