# نيفا: لغة برمجة بالعربي

[![CI](https://github.com/RIO4140/niva/actions/workflows/ci.yml/badge.svg)](https://github.com/RIO4140/niva/actions/workflows/ci.yml)

نيفا لغة برمجة عربية كاملة: تكتب الكود بالعربي، وتشغّله في ترمنال نيفا الرسمي، أو جرّبه في الملعب في المتصفح.

صنع بواسطة محمود عبد النبي.

## تنزيل ترمنال نيفا

التجربة الكاملة للغة، بالعرض الصحيح من اليمين لليسار، في تطبيق ترمنال نيفا الرسمي:

- أندرويد: [niva-terminal-1.2.19.apk](https://github.com/RIO4140/niva/releases/download/v1.2.19/niva-terminal-1.2.19.apk)
- ويندوز: قريبا
- ماك: قريبا

نيفا تعمل في ترمنال نيفا الرسمي فقط، لأن الطرفيات الأخرى تعرض الكود من الشمال لليمين بلا وصل.

## جرّب بلا تثبيت

في [الملعب](https://rio4140.github.io/niva/playground/) تكتب كود بالعربي وتشغله مباشرة من المتصفح من غير تثبيت.

## المحرك

المحرك مكتوب بلغة Rust، إصداره 1.0.0، ويعمل داخل ترمنال نيفا الرسمي. وتشغيل برنامجك أمر واحد في الترمنال: `نيفا برنامج.نيفا`.

وللتجميع الأصلي: `نيفا ابن --أصلي برنامج.نيفا` يبني ثنائي أصلي يعمل وحده.

وأمر `ابن` وحده يبني ملف `.نيفاب` يعمل على أي جهاز فيه نيفا، و`ابن --مستقل` يبني ملف تنفيذي مستقل.

والمحرك يعمل داخل تطبيق ترمنال الأندرويد.

## الوضع التفاعلي

في ترمنال نيفا الرسمي يمكنك أن تفتح الوضع التفاعلي من غير ملف، أو بالأمر `نيفا --تفاعلي`. تكتب جملة في سطر، والتعبير وحده يطبع قيمته، والكتل مثل الدالة والشرط والحلقة تكمل بسطور زيادة، وسطر فارغ يلغي الكتلة. والأوامر المتاحة هي `:مساعدة` و`:اعرض` و`:امسح-المحفوظات` و`:مسح` و`:اسمح-بالشبكة` و`:خروج`.

والأمثلة في `engine/README.md`.

## المكتبة القياسية

المكتبة القياسية واسعة، وتغطي النص والملفات والنظام والشبكة والحزم والطرفية والمراقبة، ومعها رياضيات ووقت وبحث وفرق وجسون وعمليات وأرقام عشوائية. والشبكة مغلقة في العادي وتفتح بعلم `--اسمح-بالشبكة`، والثنائي الأصلي يقبل HTTP فقط ويرفض HTTPS بينما الملعب يقبل HTTPS، وعمليات خاملة في الملعب والتشغيل مرفوض في التطبيق، وحزم تثبت الحزم من GitHub وأمر `حدث حزم` يحدثها.

```
استورد رياضيات
اطبع رياضيات.جذر(16)
```

## المميزات

في نيفا تكتب متغيرات وشروط وحلقات ودوال وقوائم وقواميس، وتطبع وتفهرس، وتعالج الأخطاء بمحاولة وماعدا وأخيرا، وتكتب تعليقات ونصوص وأرقام عربية وغربية وترقيم عربي. وفيها مطابقة أنماط مع `طابق` و`حال`، وصفوف ومجموعات وفهميات تبني القوائم والقواميس، ومولدات مع `ولد` و`ولد من` تعمل مع التشغيل العادي ومع الثنائي الأصلي، ومديرو سياق مع `عند` لإدارة الموارد، وأنواع عامة واختيارية، فتكتب `س: عدد = ٥` وتكتب `دالة جمع(أ: عدد): عدد:`، و`أي` تعني بلا فحص. وفئات بسيطة مثل `فئة نقطة:`، وتستدعي `أنشئ نقطة(٣، ٤)` لتنشئ منها، بطرق وحقول بالنقطة و`نفس` داخل الطرق، ووراثة مع `ورث`، وواجهات مع `واجهة`. ووحدات تستورد ملفات `.نيفا` وتصدر أسماءها العامة.

الأخطاء بالعربي، بالسطر والعمود ونوع الخطأ. والملفات مقيدة بمجلد البرنامج في العادي، و`--اسمح-بالكل` للبرامج الموثوقة فقط. وملعب المتصفح يكتب كود بالعربي ويشغله بلا تثبيت، لكن بلا ملفات وإدخال ونوم. وفيه إضافة VS Code لتمييز صياغة ملفات `.نيفا`، وخادم لغة (`niva-lsp`) يشخص ويكمل ويمرر فوق stdio.

## قواعد اللغة

نيفا لها كلمات محجوزة ثابتة، فالجملة العربية الحرة لا تعمل فيها. والكود يعرض من اليمين لليسار مثل القراءة العربية، والكلمات العربية رموز داخله، والنصوص داخل علامات التنصيص لا تترجم أبدا. والتشكيل يُتجاهل، والأرقام العربية المشرقية ٠١٢٣ والغربية 0123 مقبولة، ومعها الفاصلة العربية ، والفاصلة المنقوطة العربية ؛. وفيه ثابتان: باي وه. واسم المتغير كلمة واحدة بلا مسافات، عربي أو إنجليزي، و`اطبع` تعمل بأقواس ومن غير أقواس. والدالة تفتح نطاق جديد، فالمتغير داخلها غير متاح خارجها، أما الحلقة والشرط فلا يفتحان نطاق جديد ومتغير الحلقة يبقى بعدها.

## مثال كامل

كود نيفا:

```
دالة تقدير(درجة):
    إذا درجة >= ٩٠:
        ارجع "ممتاز"
    وإلا إذا درجة >= ٥٠:
        ارجع "ناجح"
    وإلا:
        ارجع "راسب"
اطبع تقدير(٨٥)
```

الناتج:

```
ناجح
```
