# Rio — لغة برمجة بالعربي

صنع بواسطة محمود عبد النبي.

## المحرك المستقل (Rust)

محرك تنفيذ مكتوب بـ Rust:
Lexer + Parser + AST + Semantic Analyzer +
Tree-Walking Interpreter، بملفات `.rio`، وبدون
Compiler إلى لغة آلة في v1.

الكود std فقط ومحمول، فيمكن بناؤه لـ Windows وLinux
وAndroid، والنسخة المبنية هنا Linux، وبناء Windows
وAndroid خطوة إصدار لاحقة.

## التشغيل

البناء بيحتاج Rust بس، والتشغيل بعد البناء مش بيحتاج
حاجة تانية:

```bash
cd engine
cargo build --release
./target/release/rio examples/01-hello.rio
./target/release/rio program.rio
cargo test   # اختبارات المحرك: 9 وحدة + 11 تكامل
```

الملف التنفيذي `rio` بيشتغل لوحده.

انظر `engine/README.md` للتشغيل والأمثلة.

## المميزات

- متغيرات، طباعة، شروط، حلقات، دوال، قوائم، قواميس،
  فهرسة، محاولة/ماعدا/أخيرا، تعليقات، نصوص، أرقام
  عربية وغربية، ترقيم عربي.
- دوال مدمجة، بالإضافة إلى `اطبع` كجملة.
- أخطاء بالعربي، بالسطر والعمود ونوع الخطأ.

## قواعد اللغة (مختصرة)

- لغة صورية بكلمات محجوزة ثابتة بالفصحى، ليست جملا عربية حرة.
  الجملة العربية الحرة لن تعمل، وهذا تعريف أي لغة برمجة في العالم.
- اتجاه الكود مثل لغات العالم (من الشمال لليمين)، والكلمات العربية
  رموز داخله. النصوص العربية داخل علامات التنصيص لا تترجم أبدا.
- المحلل متسامح: يشيل التشكيل، ويوحد الهمزات في الكلمات المحجوزة فقط،
  ويقبل الأرقام العربية المشرقية ٠١٢٣ والغربية 0123، والفاصلة العربية ،
  والفاصلة المنقوطة العربية ؛.
- أسماء المتغيرات: كلمة واحدة من غير مسافات، عربي أو إنجليزي.
  التنضيف فيها للتشكيل فقط، فـ مدرسة ليست مدرسه، ولا يدمجهما المحلل.
- `اطبع` تعمل بأقواس ومن غير أقواس: `اطبع "مرحبا"` و `اطبع("مرحبا")`.
- الدالة تفتح نطاقا جديدا، ومتغير داخلها غير متاح خارجها.
  الحلقة والشرط لا يفتحان نطاقا، ومتغير الحلقة يبقى بعدها.

## مثال كامل

كود Rio:

```
دالة تقدير(درجة):
    إذا درجة >= ٩٠:
        ارجع "ممتاز"
    وإلا إذا درجة >= ٥٠:
        ارجع "ناجح"
    وإلا:
        ارجع "راسب"
اطبع تقدير(٨٥)
```

الناتج:

```
ناجح
```
