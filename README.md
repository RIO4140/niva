# نيفا — لغة برمجة بالعربي

صنع بواسطة محمود عبد النبي.

## التثبيت

نيفا محرك Rust محمول — يعمل على Linux وmacOS وWindows وAndroid، والملعب يعمل في المتصفح بلا تثبيت.

**تنبيه:** على الطرفيات الأخرى قد يظهر الكود من الشمال لليمين والحروف غير موصولة — هذه مشكلة عرض في الطرفية نفسها وليست في اللغة. التجربة الكاملة بالعرض الصحيح من اليمين لليسار هي في تطبيق ترمنال نيفا.

### Linux وmacOS

بأمر واحد:

```bash
curl -fsSL https://raw.githubusercontent.com/RIO4140/niva/main/install.sh | bash
```

أو من داخل المستودع:

```bash
./install.sh
```

المثبّت يبني المحرك من المصدر ويثبّت الأمر `نيفا` في `~/.local/bin`، وكل رسائله بالعربي.

### Windows

ابنِ من المصدر:

```powershell
cd engine
cargo build --release
```

والملف التنفيذي `target\release\niva.exe` يعمل لوحده.

### بلا تثبيت

جرّب اللغة في المتصفح من [الملعب](https://rio4140.github.io/niva/playground/) — اكتب كودا بالعربي وشغّله فورا.

## المحرك المستقل (Rust)

محرك تنفيذ مكتوب بـ Rust:
Lexer + Parser + AST + Semantic Analyzer +
مترجم إلى بايت كود وآلة افتراضية، بملفات `.نيفا`،
ولا يحوّل إلى لغة آلة بعد.

الكود std فقط ومحمول، ويُبنى لـ Windows وmacOS وLinux
وAndroid، والمحرك نفسه يعمل داخل تطبيق ترمنال الأندرويد.

## التشغيل

البناء بيحتاج Rust بس، والتشغيل بعد البناء مش بيحتاج
حاجة تانية:

```bash
cd engine
cargo build --release
./target/release/نيفا examples/01-hello.نيفا
./target/release/نيفا program.نيفا
cargo test   # اختبارات المحرك
```

الملف التنفيذي `نيفا` بيشتغل لوحده.

## الوضع التفاعلي

شغّل `نيفا` بلا ملف (أو `نيفا --تفاعلي`) للدخول في الوضع التفاعلي:
اكتب جملة في سطر، والتعبير وحده يطبع قيمته،
والكتل (دالة، إذا، بينما...) تكمل بسطور إضافية،
وسطر فارغ يلغي الكتلة. الأوامر: `:مساعدة` و`:اعرض`
و`:مسح` و`:خروج`.

انظر `engine/README.md` للتشغيل والأمثلة.

## المكتبة القياسية

أربع وحدات جاهزة، بلا ملفات:

- `رياضيات`: جذر، قوة، جيب، جيب_تمام، ظل، لوغاريتم،
  أس_طبيعي، أرضية، سقف، والثابتان باي وهـ.
  الزوايا بالراديان.
- `عشوائي`: عدد_عشوائي (من 0 إلى 1)،
  صحيح_عشوائي (من حد أدنى إلى حد أقصى)،
  اختيار (عنصر عشوائي من قائمة).
  عشوائية للألعاب والمحاكاة، لا للتشفير.
- `وقت`: الآن (ثواني منذ 1970)، نوم (ثواني).
- `شبكة`: اجلب (رابط) — جلب HTTP بنص، مغلقة افتراضيا،
  وتفتح بعلم `--اسمح-بالشبكة`؛ النسخة الأصلية تقبل HTTP
  فقط وترفض HTTPS، أما الملعب والتطبيق فيقبلان HTTPS.

```
استورد رياضيات
اطبع رياضيات.جذر(16)
```

## المميزات

- متغيرات، طباعة، شروط، حلقات، دوال، قوائم، قواميس،
  فهرسة، محاولة/ماعدا/أخيرا، تعليقات، نصوص، أرقام
  عربية وغربية، ترقيم عربي.
- وحدات: استيراد ملفات `.نيفا`، وتصدير الأسماء العامة،
  والوصول إليها بالنقطة.
- أنواع اختيارية: مثل `س: عدد = ٥`،
  و`دالة جمع(أ: عدد): عدد:`، و`أي` يعني بلا فحص.
- فئات بسيطة: `فئة نقطة:`، وإنشاء بـ `أنشئ نقطة(٣، ٤)`،
  وطرق وحقول بالنقطة، و`نفس` داخل الطرق،
  ووراثة بـ `ورث`، وواجهات بـ `واجهة`.
- دوال مدمجة، بالإضافة إلى `اطبع` كجملة.
- أخطاء بالعربي، بالسطر والعمود ونوع الخطأ.
- الملفات مقيدة بمجلد البرنامج افتراضيا،
  و`--اسمح-بالكل` للبرامج الموثوقة فقط.
- ملعب متصفح (WebAssembly) في `playground/`:
  اكتب كودا بالعربي وشغّله بلا تثبيت. يبنى بـ
  `wasm-pack build --target web`، والملفات والإدخال
  والنوم غير مدعومة فيه.
- إضافة VS Code في `editors/vscode/`:
  تمييز صياغة لملفات `.نيفا`.
- خادم لغة (LSP) في `editors/lsp/`:
  تشخيصات وإكمال وتمرير فوق stdio (`niva-lsp`).

## قواعد اللغة (مختصرة)

- لغة صورية بكلمات محجوزة ثابتة بالفصحى، ليست جملا عربية حرة.
  الجملة العربية الحرة لن تعمل، وهذا تعريف أي لغة برمجة في العالم.
- الكود يُعرض من اليمين لليسار (مثل القراءة العربية)، والكلمات العربية
  رموز داخله. النصوص العربية داخل علامات التنصيص لا تترجم أبدا.
- المحلل متسامح: يشيل التشكيل، ويوحد الهمزات في الكلمات المحجوزة فقط،
  ويقبل الأرقام العربية المشرقية ٠١٢٣ والغربية 0123، والفاصلة العربية ،
  والفاصلة المنقوطة العربية ؛.
- أسماء المتغيرات: كلمة واحدة من غير مسافات، عربي أو إنجليزي.
  التنضيف فيها للتشكيل فقط، فـ مدرسة ليست مدرسه، ولا يدمجهما المحلل.
- `اطبع` تعمل بأقواس ومن غير أقواس: `اطبع "مرحبا"` و `اطبع("مرحبا")`.
- الدالة تفتح نطاقا جديدا، ومتغير داخلها غير متاح خارجها.
  الحلقة والشرط لا يفتحان نطاقا، ومتغير الحلقة يبقى بعدها.

## مثال كامل

كود نيفا:

```
دالة تقدير(درجة):
    إذا درجة >= ٩٠:
        ارجع "ممتاز"
    وإلا إذا درجة >= ٥٠:
        ارجع "ناجح"
    وإلا:
        ارجع "راسب"
اطبع تقدير(٨٥)
```

الناتج:

```
ناجح
```
