# الأمثلة

كل الأمثلة في `engine/examples/`، وتشغل من جذر المستودع
بأمر مثل:

```bash
نيفا engine/examples/01-hello.نيفا
```

ومثال الوحدات (09) يحتاج `حساب.نيفا` بجانبه في نفس
المجلد — وهو كذلك.

| المثال | ماذا يعلم |
| --- | --- |
| 01-hello | الطباعة والحساب |
| 02-variables | المتغيرات والأرقام العربية والنوع |
| 03-conditions | الشروط والمنطق |
| 04-loops | الحلقات الأربع |
| 05-functions | الدوال والنطاق |
| 06-lists-dicts | القوائم والقواميس والعضوية |
| 07-try-files | المحاولة والأخطاء والملفات |
| 08-full-program | برنامج كامل: حساب درجات فصل |
| 09-modules | استيراد وحدة وتصدير |
| 10-types | الأنواع التدريجية |
| 11-classes | الفئات والمنشئ والطرق |
| 12-inheritance-interfaces | الوراثة والواجهات |
| 13-closures | الدوال المرجعة والعدادات |
| 14-lambdas | الدوال المجهولة |
| 15-methods | دوال النصوص والقوائم |
| 16-stdlib | المكتبة القياسية |
| 17-word-operators | المقارنات بالكلمات |
| 18-عمليات | وحدة عمليات: تشغيل برنامج وانتظاره |
| 19-خادم | خادم HTTPS (شبكة.اخدم): معالج يعيد نصا (يحتاج --اسمح-بالخادم) |
| 20-خادم-حديث | خادم HTTPS يتحدث HTTP/2 وHTTP/1.1 معا (نفس اخدم، التفاوض بـ ALPN) |
| حساب | وحدة مثال للاستيراد |

ومثال العمليات (18) يحتاج `عمليات-مساعد.نيفا`
و`عمليات-فاشل.نيفا` بجانبه في نفس المجلد — وهما كذلك.

ومثال الخادم (19) يحتاج `server-cert.pem`
و`server-key.pem` بجانبه في نفس المجلد — وهما
كذلك (شهادتا اختبار لـ localhost فقط) — ولا يعمل
في الاختبار التلقائي لأنه يحجب (يخدم حتى
المقاطعة): شغّله بـ `نيفا --اسمح-بالخادم
19-خادم.نيفا` ثم افتح https://127.0.0.1:8443/.

ومثال الخادم الحديث (20) هو نفس الخادم لكنه
يتحدث HTTP/2 أيضا: العميل يعرض [h2, http/1.1]
بـ ALPN والخادم يختار؛ جرّبه بـ
`curl --http2 -k https://127.0.0.1:8443/`
ثم بـ `curl --http1.1 -k https://127.0.0.1:8443/`
— الجسم نفسه في الحالتين، والإصدار هو الفرق.
ولا يعمل في الاختبار التلقائي لأنه يحجب مثل 19.

وكل مثال مختبر تلقائيا: اختبار `examples_pass` يشغلها
كلها ويقارن خرجها.
