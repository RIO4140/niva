## أنواع الأخطاء

كل خطأ عربي، بنوعه وسطر ه وعموده، وخروج 1، بلا
انهيار:

- `خطأ نحوي` — جملة لا تطابق القواعد.
- `خطأ دلالي` — متغير غير معرف، أو اسم طريقة غير
  معروف لنوع معلوم، أو نوع معلن خاطئ. ويكتشف قبل
  أي تنفيذ.
- `خطأ نوع` — عملية على نوع خاطئ وقت التشغيل.
- `خطأ وقت التشغيل` — قسمة على صفر، أو فهرس خارج
  النطاق، أو تجاوز حد عمق الاستدعاء.
- `خطأ إدخال/إخراج` — ملف أو وحدة غير موجودة.

## الحدود

- حد عمق الاستدعاء 500: تجاوزه خطأ عربي نظيف.
- حد تكرار الحلقة 1,000,000.
- حد تكرار `مدى` 1,000,000 عنصر.

## الملفات

`اقرأ_ملف(مسار)` و`اكتب_ملف(مسار، نص)` و`ادخل(سؤال)`
دوال مدمجة. والملفات مقيدة بمجلد البرنامج افتراضيا
(انظر فصل التثبيت)، و`--اسمح-بالكل` للبرامج الموثوقة
فقط.
