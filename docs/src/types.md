الخرج:

```
٥
٧
محمود
```

والأنواع اختيارية: تكتبها حيث تريد، وتتركها حيث تريد.
الأنواع: `عدد`، `نص`، `منطقي`، `قائمة`، `قاموس`،
`لاشيء`، `دالة`، `وحدة`، `فئة`، `كائن`، `واجهة`،
و`أي` (يعني بلا فحص).

والقواعد:

- نوع المتغير بعد نقطتين: `س: عدد = ٥`.
- نوع الدالة: المعاملات بعد نقطتين، ونوع الإرجاع بعد
  نقطتين بعد القوس (`دالة جمع(أ: عدد، ب: عدد): عدد:`).
  والنقطتان بعد نوع الإرجاع إلزاميتان.
- المفسر يفحص الأنواع المعلنة وقت الاستدعاء والتعيين.
- والنوع غير المعلن يمرر للتشغيل (تدرج): يعمل بلا
  فحص ثابت، ويفشل وقت التشغيل بخطأ نوع عربي عند
  الخطأ.

والتحليل الدلالي يعمل قبل أي تنفيذ: برنامج فيه خطأ
دلالي لا يطبع شيئا ولا يكتب ملفا — يرفض كاملا قبل أن
يبدأ.
