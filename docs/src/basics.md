المتغير يعرّف بأول تعيين (`س = ٥`)، ويقبل أي نوع،
ويقبل إعادة التعيين بنوع آخر. والتعيين داخل دالة يكتب
على أقرب تعريف موجود — فإذا كان الاسم معرّفا خارج
الدالة عدّله، وإلا عرّفه محليا.

## الأرقام

الأرقام العربية (٠١٢٣٤٥٦٧٨٩) والغربية (0123456789)
تعمل معا، والأرقام العشرية والسالبة كذلك. والعمليات:
`+` و`-` و`*` و`/` و`%`، والمقارنات `==` و`!=` و`<`
و`>` و`<=` و`>=`، والمنطق `و` و`أو` و`ليس`، والعضوية
`في`.

والقسمة على صفر خطأ تشغيل عربي، لا قيمة خاصة.

## النصوص

النص بين علامتي تنصيص `"..."`. والهروب `\"` و`\\` و`\n`
يعمل داخل النص. والنصوص تدمج بـ `+`، وتقارن بـ `==`.

## المنطقي ولاشيء

`صحيح` و`خطأ` هما القيمتان المنطقيتان، و`لاشيء` قيمة
فارغة (ترجعها الدالة بلا `ارجع`، وطريقة `أضف`).

## الطباعة والنوع

`اطبع` جملة تطبع قيمة أو أكثر. و`نوع(قيمة)` ترجع اسم
النوع نصا: `عدد` أو `نص` أو `منطقي` أو `قائمة` أو
`قاموس` أو `لاشيء` أو `دالة` أو `وحدة` أو `فئة` أو
`كائن` أو `واجهة`.
