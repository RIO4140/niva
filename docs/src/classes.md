# الفئات

## الفئة والمنشئ والطرق

```niva
{{#include ../../engine/examples/11-classes.niva}}
```

الخرج:

```
3

```

والفئة تعرّف بـ `فئة اسم:`، والمنشئ طريقة باسم
`أنشئ`، والإنشاء بـ `أنشئ اسم(...)`. و`نفس` مربوط
تلقائيا داخل الطرق وليس معاملا. والحقول ديناميكية
(تعرف بالتعيين)، وكتابة طريقة داخلها تستمر لأن
الحقول مشتركة. والحقل يحجب طريقة بنفس الاسم.

## الوراثة والواجهات

```niva
{{#include ../../engine/examples/12-inheritance-interfaces.niva}}
```

الخرج:

```
طالب: محمود
يدرس
محمود
```

والصيغة الثابتة: `ورث` أولا ثم `واجهة`
(`فئة طالب ورث شخص واجهة قابل_للطباعة:`). والبحث عن
الطريقة يمشي سلسلة الأساس، وطريقة الابن تغلب،
والمنشئ يورث إذا لم يكن للابن منشئ. والواجهة تعرّف
طرقا بـ `مرر` فقط، والالتزام بها (الوجود + عدد
المعاملات) يفحص وقت تعريف الفئة.
