# تنزيل تطبيق نيفا

تطبيق ترمنال نيفا للأندرويد — اكتب كود نيفا بالعربي وشغّله على تليفونك.

**الإصدار:** ١٫٠٫٠
**الحجم:** ٣٠١ كيلوبايت
**يحتاج:** أندرويد ٧٫٠ أو أحدث

[نزّل التطبيق (APK)](https://github.com/RIO4140/niva/releases/download/v1.0.0/niva-terminal.apk)

## التثبيت

١. نزّل الملف.
٢. افتحه واضغط «تثبيت».
٣. لو طلب السماح بالتثبيت من مصادر غير معروفة، اسمح.
٤. افتح التطبيق واكتب كودك.
