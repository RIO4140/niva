# الوحدات والمكتبة القياسية

## وحدات الملفات

ملف الوحدة `حساب.niva`:

```niva
{{#include ../../engine/examples/حساب.niva}}
```

والبرنامج الذي يستوردها:

```niva
{{#include ../../engine/examples/09-modules.niva}}
```

الخرج:

```
٧
٤٢
٣
```

والقواعد: الاستيراد من مجلد البرنامج فقط، والتحميل
مرة واحدة، وكشف الاستيراد الدائري، والوصول للمصدّر
فقط (`صدّر` يعلن الأسماء العامة؛ والوحدة بلا `صدّر`
لا تصدّر شيئا). والصيغ: `استورد وحدة`، و`استورد وحدة
باسم مختصر`، و`من وحدة استورد اسم1، اسم2`.

## المكتبة القياسية

ثلاث وحدات أصلية، بلا ملفات، وتعمل في أي مكان:

```niva
{{#include ../../engine/examples/16-stdlib.niva}}
```

الخرج:

```
٤
١٠٢٤
٣
٤
٣٫١٤١٥٩٢٦٥٣٥٨٩٧٩٣
٢٫٧١٨٢٨١٨٢٨٤٥٩٠٤٥
٥
صحيح
صحيح
صحيح
صحيح
```

- `رياضيات`: جذر، قوة، جيب، جيب_تمام، ظل، لوغاريتم،
  أس_طبيعي، أرضية، سقف، والثابتان باي وهـ. والزوايا
  بالراديان.
- `عشوائي`: عدد_عشوائي (من 0 إلى 1)، صحيح_عشوائي
  (من حد أدنى إلى حد أقصى)، اختيار (عنصر عشوائي من
  قائمة). عشوائية للألعاب والمحاكاة، لا للتشفير.
- `وقت`: الآن (ثواني منذ 1970)، نوم (ثواني).

وملف بنفس اسم وحدة أصلية في مجلد البرنامج لا يحجب
الوحدة الأصلية أبدا. والمكتبة مفسر فقط في v1.
