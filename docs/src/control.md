## الحلقات

```niva
{{#include ../../engine/examples/04-loops.niva}}
```

الخرج:

```
0
1
2
بعد الحلقة:
2
0
1
2
تكرار
تكرار
3
4
```

- `لكل متغير في قائمة:` — يجول على عناصر قائمة (أو
  ناتج `مدى`)، ومتغير الحلقة يبقى متاحا بعدها.
- `بينما شرط:` — يكرر ما دام الشرط صحيحا.
- `كرر N مرات:` — يكرر N مرة.
- `كرر طالما شرط:` — مثل `بينما` بصيغة أخرى.
- `اكسر` يخرج من الحلقة، و`تابع` يتخطى إلى التكرار
  التالي.

وحد تكرار الحلقة 1,000,000 تكرار: تجاوزه خطأ تشغيل
عربي («هل الحلقة لا تنتهي؟»).
