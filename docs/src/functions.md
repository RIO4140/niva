## الاستدعاء المجرد ومرجع الدالة

الدالة تُستدعى بالأقواس عادة (`جمع(٢، ٣)`)، والاسم
المنقّط وحده يُستدعى مجردا — بلا أقواس — بمعاملاته
على السطر نفسه (`م.اقسم ١`)؛ أما الاسم المسطح فلا
يُستدعى مجردا أبدا ويحتاج الأقواس. و`اطبع` كلمة
مفتاحية لا دالة (`اطبع س`).

ومرجع دالة كعبارة مجردة — لا استدعاء ولا إسناد ولا
تمرير — خطأ عربي يسمي الدالة: `دالة بلا استدعاء:
جذر — استدعها بالأقواس أو أسندها إلى متغير`. أما
الإسناد (`س = جذر`) والتمرير كمعامل والطباعة
(`اطبع جذر`) فصالحة: الدالة قيمة كاملة هناك.

## إصدار المحرك

`إصدار_المحرك()` بلا وسائط ترجع نص الإصدار المجرد
وحده (مثال `١٫٠٫٠`)؛ و`النسخة()` ترجع اللافتة
كاملة (`محرك نيفا ١٫٠٫٠`) — وفي الترمنال (يمرّر
التطبيق نسخته في `NIVA_TERMINAL_VERSION`) تصير
اللافتة «ترمنال نيفا ١٫٢٫١١ (محرك ١٫٠٫٠)»؛
و`إصدار_المحرك()` يبقى نسخة اللغة وحدها.

## الدوال المجهولة (lambdas)

```niva
{{#include ../../engine/examples/14-lambdas.نيفا}}
```

الخرج:

```
١٠
١٢
١٢
١٠
١١

```

والصيغة `دالة_مجهولة(معاملات): تعبير` — تعبير واحد
فقط، بإرجاع ضمني، بلا جمل داخلية. والدالة المجهولة
قيمة كاملة: تمرر كمعامل، وترجع من دالة، وتلتقط بيئتها
معجميا كالـ closures، وتقبل نوع معامل اختياري
(`س: عدد`).

ملاحظة: `اطبع (...)` صيغة خاصة تأكل القوس الأول،
فالاستدعاء الفوري داخل `اطبع` يحتاج تعيينا أولا:

```niva
مضاعف = دالة_مجهولة(س): س * 2
اطبع مضاعف(5)
```

أما الاستدعاء الفوري في تعيين أو معامل أو شرط فيعمل
مباشرة.
