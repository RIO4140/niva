# مقدمة

نيفا لغة برمجة بالعربي. تكتب الكود بكلمات عربية، وتشغله
بمحرك مكتوب بلغة Rust، بلا Python في التشغيل أو المحرك
أو الاختبارات.

جرّبها فورا بلا تثبيت في [ملعب المتصفح](../playground/).

اللغة صورية بكلمات محجوزة ثابتة بالفصحى — ليست جملا
عربية حرة. تكتب `إذا` و`دالة` و`اطبع`، لا جملا نثرية.
والكتل بالمسافة البادئة، مثل Python.

## لمن هذه اللغة

- لمن يتعلم البرمجة أول مرة، بالعربي.
- لمن يريد كتابة برامج حقيقية صغيرة: حسابات، قوائم،
  ملفات، فئات، وحدات.
- لمن يريد لغة عربية حديثة: دوال مجهولة، closures،
  أنواع تدريجية، مكتبة قياسية.

## حالة اللغة

الإصدار الحالي 1.0.0. المفسر (يمشي الشجرة) هو المسار
الافتراضي والكامل. والـ VM التجريبي (`--افتراضي`) يدعم
الأساسيات والدوال والقوائم والفئات، وما زال قيد البناء.

## ما ستتعلمه هنا

التثبيت، ثم أول برنامج، ثم الأساسيات: المتغيرات
والشروط والحلقات والدوال والقوائم والفئات والوحدات
والأنواع، ثم الأخطاء والملفات، ثم مرجع كامل.

كل مثال كود في هذا التوثيق مأخوذ من ملف مثال حقيقي
في المستودع، أو مختبر بالتشغيل — بلا أمثلة وهمية.
