# التثبيت والتشغيل

## التثبيت (Linux)

من داخل المستودع:

```bash
./install.sh
```

المثبّت يبني المحرك من المصدر ويثبّت الأمر `niva` في
`~/.local/bin`، وكل رسائله بالعربي. وأمر التثبيت بأمر
واحد موجود في README الرئيسي للمستودع.

ويحتاج المثبّت إلى Rust (cargo). وإذا لم يكن موجودا،
يعرض تثبيته ويثبته بعد موافقتك.

## التشغيل

```bash
niva برنامج.niva
```

أوامر المحرك:

- `niva برنامج.niva` — تشغيل ملف بالمفسر الافتراضي.
- `niva` بلا ملف، أو `niva --repl` — دخول REPL التفاعلي.
- `niva --ast برنامج.niva` — عرض الشجرة النحوية.
- `niva --vm برنامج.niva` — التشغيل بالـ VM التجريبي.
- `niva --allow-all برنامج.niva` — السماح بملفات خارج
  مجلد البرنامج (للبرامج الموثوقة فقط).
- `niva --help` — المساعدة بالعربي.
- `niva --version` — إصدار المحرك.

## الملفات

الملفات مقيدة بمجلد البرنامج افتراضيا: `اقرأ_ملف`
و`اكتب_ملف` لا يصلان إلا إلى ملفات داخل مجلد البرنامج
الذي فيه ملف `.niva`، والمسار النسبي نسبة لمجلد
البرنامج لا لمجلد التشغيل. والهروب بـ `..` أو المسار
المطلق أو الروابط الرمزية مرفوض.
