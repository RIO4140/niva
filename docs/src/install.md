# التثبيت والتشغيل

## التثبيت (Linux)

من داخل المستودع:

```bash
./install.sh
```

المثبّت يبني المحرك من المصدر ويثبّت الأمر `نيفا` في
`~/.local/bin`، وكل رسائله بالعربي. وأمر التثبيت بأمر
واحد موجود في README الرئيسي للمستودع.

ويحتاج المثبّت إلى Rust (cargo). وإذا لم يكن موجودا،
يعرض تثبيته ويثبته بعد موافقتك.

## التشغيل

```bash
نيفا برنامج.نيفا
```

أوامر المحرك:

- `نيفا برنامج.نيفا` — تشغيل ملف بالمفسر الافتراضي.
- `نيفا` بلا ملف، أو `نيفا --تفاعلي` — دخول الوضع التفاعلي.
- `نيفا --شجرة برنامج.نيفا` — عرض الشجرة النحوية.
- `نيفا --افتراضي برنامج.نيفا` — التشغيل بالـ VM التجريبي.
- `نيفا --اسمح-بالكل برنامج.نيفا` — السماح بملفات خارج
  مجلد البرنامج (للبرامج الموثوقة فقط).
- `نيفا --مساعدة` — المساعدة بالعربي.
- `نيفا --نسخة` — إصدار المحرك.

## الملفات

الملفات مقيدة بمجلد البرنامج افتراضيا: `اقرأ_ملف`
و`اكتب_ملف` لا يصلان إلا إلى ملفات داخل مجلد البرنامج
الذي فيه ملف `.نيفا`، والمسار النسبي نسبة لمجلد
البرنامج لا لمجلد التشغيل. والهروب بـ `..` أو المسار
المطلق أو الروابط الرمزية مرفوض.
